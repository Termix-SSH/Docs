# Translations

Never hard code text. Put every string your plugin shows in `locales/en.json`:

```json
{
  "tab": { "title": "Hello", "empty": "No notes yet." },
  "permissions": {
    "use": {
      "title": "Use Hello",
      "description": "Open the Hello tab and keep notes in it."
    }
  }
}
```

Keys in the manifest (`titleKey`, `labelKey` and so on) and calls to `t()` look up this file. Each plugin has its own namespace, so your `tab.title` never clashes with another plugin's.

```tsx
const { t } = useTranslation();
return <p>{t("tab.empty")}</p>;
```

A key you don't define falls back to Termix's shared strings, like `common.save`.

Outside a component, use `app.t("tab.title")`.

## Other languages

Only write English. Other languages go in `locales/translated/<language>.json`. Official plugins get them translated automatically. If you ship your own, use the same format.

# Command History

Termix keeps a history of commands you run over SSH, per host, so you can look back at what was run and when.

## Turning it on or off

Each host has its own **Enable Command History** toggle in its settings. It's on by default. Turn it off for a host if you don't want its commands logged, for example a host where commands might contain sensitive information.

## Viewing history

History is searchable from the terminal, letting you jump back to a command you ran earlier on that host without scrolling through your terminal's scrollback.

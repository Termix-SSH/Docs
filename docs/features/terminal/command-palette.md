# Command Palette

The command palette is a quick search box for jumping to a host or action without touching the sidebar.

## Opening it

Double tap the left Shift key to open it from anywhere in Termix.

## What you can do with it

- Jump straight into a terminal, file manager, tunnel, Docker, host metrics, or remote desktop session for any host
- Open recent activity, so you can pick up where you left off
- Search across everything by typing, instead of scrolling the sidebar

It's built to be fast for people who manage a lot of hosts and don't want to hunt through folders every time.

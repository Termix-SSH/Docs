# Session Recording

Session Recording saves a text log of everything that happens in an SSH terminal session, so you can look back at exactly what was run and what the output was.

This page covers SSH session recording. For recording RDP, VNC, and Telnet sessions as video instead, see [Remote Desktop](/setup/remote-desktop#session-recording).

## Turning it on

Each host has its own **Enable Session Logging** toggle in its settings. Turn it on and every SSH session on that host gets recorded from then on.

## Viewing recordings

Open the Session Logs panel from the sidebar to see a list of recordings, with the host, start time, duration, and size. Open one to read through it, or download it.

## Retention

Recordings are kept for 30 days, then deleted automatically along with their database entry.

# Dashboard

The Dashboard is the home screen you land on after logging in. It's made of cards you can rearrange, resize, and turn on or off to build a layout that fits how you work.

## Cards

- **Status Bar.** Termix version, uptime, database health, and how many hosts are online.
- **Counters Bar.** Total counts of hosts, credentials, and tunnels.
- **Quick Actions.** Shortcuts for adding a host, adding a credential, or jumping to settings.
- **Host Status.** A live list of your hosts with CPU and RAM per host.
- **Network Graph.** A visual map of how your hosts connect to each other. See [Network Graph](./network-graph) for more.

## Editing the layout

Turn on edit mode to drag cards into a new order or resize them. Cards you don't want can be turned off entirely, and added back later from the same menu.

## Support

Please be as detailed as possible in your issue, preferably written in English. You can also join the [Discord](https://discord.gg/jVQGdvHDrf) server and visit the support
channel, however, response times may be longer.

# Network Graph

The Network Graph is a dashboard card that maps out how your servers connect to each other. It's built by hand, not auto discovered, so it shows your network the way you actually think about it.

## Adding hosts to the graph

Add a node and pick one of your existing hosts to represent it. You can group nodes into folders, for example to cluster everything behind one router or in one rack together.

## Connecting hosts

Draw a connection between two nodes to show how they relate, like a jump host leading to the servers behind it, or a switch connecting a group of machines.

## Saving and sharing the layout

Your layout is saved automatically as you edit it. You can also export it and import it again later, which is useful for backing it up or moving it to another Termix instance.

# Workspaces

A workspace is a saved set of tabs. Open it and everything comes back the way you left it, in the same split layout.

This is for the groups of things you open together. Debugging the mail server might mean a terminal, the file manager, and a metrics tab. Save that once as a workspace and it is one click next time instead of six.

## Saving a workspace

Arrange your tabs the way you want them, open the Workspaces panel from the sidebar, and save. Give it a name, and a color and icon if you want to spot it quickly in the list.

A workspace stores which tabs were open, which hosts they were connected to, and how the panes were split.

## Opening a workspace

Click it. Termix opens the tabs and rebuilds the layout.

## Last Session

Termix keeps a workspace called **Last Session** up to date on its own. It always holds whatever you had open most recently, so if you close something by accident you can get it back.

You cannot rename or delete this one, and it updates by itself.

## Restoring on login

Mark one workspace as your default and Termix opens it every time you sign in. Only one workspace can be the default at a time, and picking a new one clears the old.

Set **Last Session** as your default if you want to carry on exactly where you left off.

## Managing workspaces

From the panel you can rename a workspace, change its color and icon, overwrite it with your current tabs, duplicate it, or delete it.

Overwriting is the one to use when a workspace is nearly right. Fix the tabs, then overwrite, rather than deleting and starting again.

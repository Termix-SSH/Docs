# Command palette

Press **Shift** twice quickly to open the command palette. Or click the search box at the top of the rail.

Type to search:

- **Hosts.** Enter connects. Plugins add more actions for each host.
- **Open tabs.** Jump to one.
- **Quick actions**, like adding a host or opening settings.
- **Actions from plugins**, like running a snippet in the current terminal.
- **Links** to these docs, GitHub and Discord.

Use the arrow keys to move and Enter to pick. Esc closes it.

Turn the shortcut off in **Settings**, **Interface** with **Command Palette**, or change it in **Settings**, **Keybindings**.

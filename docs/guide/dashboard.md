# Dashboard

The dashboard is the first tab you see. It shows cards: server info, host status, recent activity and quick actions. Plugins add more, like metrics or service links from [Homepage](/plugins/homepage).

## Change the layout

Press the edit button in the dashboard header.

- Drag cards to reorder them.
- Drag the column divider to change column widths.
- Drag the bottom edge of a card to change its height.
- **Add a section** lists cards you don't have yet. **From plugins** shows the ones plugins add.

**Reset** puts the default layout back. The layout is saved to your account.

## Links

The bottom of the dashboard links to GitHub, Discord, these docs and the donate page.

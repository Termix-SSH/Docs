# Settings

**Settings** opens as a tab from the bottom of the rail. The pages are in four groups. Search at the top finds any setting by name. Each page has a book icon that opens its docs.

| Group            | Pages                                                                           |
| ---------------- | ------------------------------------------------------------------------------- |
| **Your account** | Account, Security, API keys, Data and sync. See [your account](/guide/account). |
| **This app**     | Interface, Appearance, Keybindings.                                             |
| **Plugins**      | One page for each plugin that has settings.                                     |
| **This server**  | Admin pages. See [admin settings](/guide/admin-settings).                       |

## Interface {#interface}

- **Preset**: Simple, Balanced or Advanced. See [the interface](/guide/interface#how-much-is-shown).
- **Navigation**: which icons show in the rail.
- Tabs, the command palette, update checks and other behavior.
- **Preference Storage**: keep settings in this browser only, or in your account so they follow you.
- **Run setup** walks through the first run setup again.

## Appearance {#appearance}

Theme (light, dark, system, or one of Dracula, Catppuccin, Nord, Solarized, Tokyo Night, One Dark and Gruvbox), accent color, interface font, font size and language.

Terminal fonts and colors are separate. They are host settings from the [SSH Terminal](/plugins/ssh-terminal) plugin.

## Keybindings {#keybindings}

Change shortcuts for the app and for plugins, like terminal copy and paste.

## Plugin settings

Each plugin with settings gets a page under **Plugins**. Your own settings show for everyone. Admin settings for the whole server show only to admins. Each plugin's settings are listed in its reference page, like [the Docker reference](/plugins/docker/reference).

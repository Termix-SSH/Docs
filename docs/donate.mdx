# Donate

Termix is a free, open source project. There are no subscriptions or paid plans.

Donations go directly to paying for things like server costs (such as the website your on now), domain names, and time spent working on the project. Any amount helps.

<MonthlyDonations />

Termix accepts donations via cryptocurrency. Base is the preferred network (stable, low fees, fast transactions). Send to any of the addresses listed below.

To request a coin, create a [GitHub Issue](https://github.com/Termix-SSH/Support/issues/new/choose).

Currently, this is the only accepted form of donations, more may be available in the future.

# Getting started

Termix is a self-hosted server manager. You run it on your own machine and open it in a browser, the desktop app or the mobile app.

It is built from two parts:

- **The core.** Hosts, credentials, users, roles, sharing and sign in. This is the same on every install.
- **Plugins.** Everything else. The SSH terminal, file manager, remote desktop, tunnels, Docker, metrics, single sign-on and more are all plugins. You pick the ones you want.

The official plugins ship with Termix. You can turn each one on or off, and install updates for it on its own.

## Where to go next

1. [Install Termix](/install) on a server, or get the [desktop or mobile app](/install#apps).
2. Do the [first run](/install/first-run). You make the admin account and pick your plugins.
3. [Add a host](/guide/hosts) and connect to it.

After that:

- Browse the [plugins](/plugins) to see what each one does.
- Read the [guide](/guide/interface) for how the core works.
- Want to build your own plugin? Start at [Develop](/develop).

## Help

- Bugs and ideas go in [GitHub issues](https://github.com/Termix-SSH/Termix/issues/new/choose). A bug in a plugin goes in that plugin's repo. Each plugin page links to it.
- Questions are welcome in the [Discord](https://discord.gg/jVQGdvHDrf).
- You can try Termix first at [demo.termix.site](https://demo.termix.site/). Any username and password works.

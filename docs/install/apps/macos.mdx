# macOS

The desktop app works two ways. It can sign in to your Termix server, or it can run on its own with everything stored on your Mac. You pick when you first open it. See [desktop sync](/configure/desktop-sync).

## App Store

Get [Termix on the App Store](https://apps.apple.com/us/app/termix-ssh-companion/id6752672071). Apple reviews every release, so a new version can take a few days to show up there.

## Homebrew

```bash
brew tap Termix-SSH/Termix https://github.com/Termix-SSH/Termix.git
brew install --cask termix
```

The app updates itself (see [updating](/install/updating#desktop-app)). To update through Homebrew instead, run `brew upgrade --cask --greedy termix`.

The universal build runs on Intel and Apple Silicon Macs. The others are smaller and only run on one.

## With every plugin

The normal download ships with the most used plugins and downloads the rest when you turn them on. For a computer
without internet, get the build that already has every official plugin: [termix_macos_universal_full_dmg.dmg](https://github.com/Termix-SSH/Termix/releases/latest/download/termix_macos_universal_full_dmg.dmg). It needs Termix 26.10.6 or later.

Updates from inside the app switch it to the normal build, which downloads any plugin it no longer ships. On a computer
that stays offline, install the next full build by hand instead.

# iOS

The app works on its own with no Termix server, and can link to one or more servers to sync. See [mobile app](/mobile) for what it does.

## App Store

Get [Termix on the App Store](https://apps.apple.com/us/app/termix-ssh-companion/id6752672071), open it and pick how to start.

## Sideload

Every release also has an `.ipa` on [GitHub](https://github.com/Termix-SSH/Mobile/releases/latest). Install it with a sideloading tool like [AltStore](https://faq.altstore.io/).

The app's code is in the [Mobile repo](https://github.com/Termix-SSH/Mobile).

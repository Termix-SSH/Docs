# Linux

The desktop app works two ways. It can sign in to your Termix server, or it can run on its own with everything stored on your computer. You pick when you first open it. See [desktop sync](/configure/desktop-sync).

## Flatpak

```bash
wget https://github.com/Termix-SSH/Termix/releases/latest/download/termix_linux_flatpak.flatpak
flatpak install --user termix_linux_flatpak.flatpak
flatpak run com.karmaa.termix
```

To update, download the new bundle from the latest release and install it the same way. Termix tells you when a new version is out.

## AUR

```bash
yay -S termix-bin
```

The [AUR package](https://aur.archlinux.org/packages/termix-bin) is kept by the community and can be a little behind.

### Portable build

The portable build needs the Chromium sandbox set up once. Run this in the folder you unpacked:

```bash
chmod +x termix
sudo chown root:root chrome-sandbox
sudo chmod 4755 chrome-sandbox
./termix
```

Don't run Termix itself with `sudo`.

## With every plugin

The normal download ships with the most used plugins and downloads the rest when you turn them on. For a computer
without internet, get the build that already has every official plugin: [AppImage](https://github.com/Termix-SSH/Termix/releases/latest/download/termix_linux_x64_full_appimage.AppImage) or [.deb](https://github.com/Termix-SSH/Termix/releases/latest/download/termix_linux_x64_full_deb.deb), x64 only. It needs Termix 26.10.6 or later.

Updates from inside the app switch it to the normal build, which downloads any plugin it no longer ships. On a computer
that stays offline, install the next full build by hand instead.

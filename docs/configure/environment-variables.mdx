# Environment variables

Set these on the Termix server. In Docker Compose they go under `environment:`. You never need most of them. Termix works with none set.

This page is made from `env.catalog.json` in the Termix repo and from each plugin's manifest, so it matches the code.

Most switches here also exist as a setting in the app. When both are set, the environment variable wins.

### Secrets

Termix makes these on first boot and saves them in `DATA_DIR/.env`. Set them yourself only if you keep secrets somewhere else. Each one can also be read from a file: add `_FILE` to the name, like `JWT_SECRET_FILE=/run/secrets/jwt`. See [security](/configure/security#keys).

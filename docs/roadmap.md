# Roadmap

This is the plan for the next year, through the end of 2027. Day to day work and single issues are on the [Termix Roadmap board](https://github.com/orgs/Termix-SSH/projects/5), which changes every week. This page changes when the direction does.

## What we plan to do

### Do more with plugins

- More official plugins and more features in the ones we have, driven by what users ask for in issues.
- A better plugin SDK and template, so community plugins are easier to write, test and publish.
- More plugins on the mobile app and the desktop app, not only in the browser.

### Keep improving security

- Limit which files a plugin can read on the desktop app.
- Make desktop builds reproducible, like plugins and Docker images already are.
- Publish plugin signatures to a public transparency log.
- Get an outside security audit and fix what it finds.

### Work for larger teams

- Better tools for admins with many users and hosts: roles, approvals, audit and reporting.
- Better support for single sign-on, directories and existing access tools.
- Make big installs fast on Postgres and MySQL with thousands of hosts.

### Reach more people

- Easier install and first run on every platform.
- Better docs, demo videos and translations.
- Listings in more stores and package managers.

## What we won't do

- A hosted or paid version of Termix. It stays free and self-hosted.
- Features that send your data to us. Telemetry stays opt in.
- Closed source parts, in core or in official plugins.
- Big new features in core. New features go in plugins, and core only gets the hooks they need.

## Changes to this plan

Ideas and requests are welcome in [GitHub issues](https://github.com/Termix-SSH/Termix/issues). We look at this page at least every few months and update it when plans change.

# 环境变量

| 配置名称        | 变量             | 默认值   | 说明                                                                                                                                       |
|----------------|------------------|---------|--------------------------------------------------------------------------------------------------------------------------------------------|
| 端口           | `PORT`           | `8080`  | 前端 Web 应用的端口。无需暴露额外端口。端口不得在受限范围 `30001–30005` 内。                                                                      |
| 启用 SSL       | `Enable_SSL`     | `false` | 参阅 [SSL](/ssl) 了解如何启用 SSL 加密的更多信息。                                                                                             |
| OIDC Client ID | `OIDC_CLIENT_ID` | `none`  | 参阅 [OIDC](/oidc#环境变量) 了解如何通过环境变量覆盖 OIDC 配置的更多信息。                                                          |
| Vite Base Path | `VITE_BASE_PATH` | `/`     | 参阅[反向代理](/reverse-proxy#更改基础路径)了解如何更改 Termix 基础路径的更多信息。                                                         |
| PUID/PGID      | `PUID` / `PGID`   | `1000`  | 将容器内部用户映射到宿主机上的用户                                                                                                              |

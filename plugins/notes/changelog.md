## 1.0.0

### Added

- Markdown notes for each host, for each folder, and private notes of your own
- A Notes tab with a list, search, pins and tags, and a Write and Preview editor with a small toolbar
- Copy and Send to terminal buttons on code blocks
- Clickable task lists
- A notes panel beside any SSH terminal
- Actions to list, read, create and add to host notes for the assistant and automations

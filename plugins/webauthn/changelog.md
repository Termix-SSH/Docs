## 1.1.0

### Added

- A security key or passkey can be the step after your password. Turn it on in Settings, Security
- The security key step counts for a login rule that requires a second factor

## 1.0.2

### Changed

- The plugin name and description show in your language

## 1.0.1

### Changed

- Translated into every supported language

## 1.0.0

### Added

- First release
- Sign in with a passkey or security key instead of a password
- Counts as a second factor when it checks your PIN or fingerprint
- More than one passkey, including synced ones

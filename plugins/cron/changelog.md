## 1.0.0

### Added

- Turn on, turn off, run and delete jobs through Termix actions
- List, add, change and delete cron jobs on a host
- A schedule helper with a plain summary and the next run times
- Turn jobs off without losing them, and run any job now
- Edit another user's crontab, or the whole crontab as text
- See /etc/crontab, /etc/cron.d and the hourly to monthly scripts
- Read the cron log
- A Cron card in Host Metrics

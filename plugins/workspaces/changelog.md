## 1.1.1

### Added

- Saved workspaces in the command palette
- A read action that lists workspaces, for the assistant and the CLI

### Changed

- Settings use the Termix tile look
- Needs Termix 26.11.1 or newer
- Form labels match the rest of Termix
- Toolbars, loading screens, back buttons and Save bars match the rest of Termix

### Fixed

- A failed save no longer leaves an uncaught error behind the toast

## 1.1.0

### Added

- Workspaces dashboard card: open a saved workspace or your last session in one click

## 1.0.2

### Changed

- The plugin name and description show in your language

## 1.0.1

### Changed

- Translated into every supported language

## 1.0.0

### Added

- First release
- Save your tabs and split layout as a named workspace
- Reopen it in one click
- Recover your last session
- Syncs between the desktop app and a Termix server

## 1.0.0

### Added

- A host first layout: a tree of folders, hosts and sub hosts on the left and the selected host on the right
- Containers and VMs that plugins list under a host in the tree, opening in that plugin's tab
- A tab for every tool and session a host has, with an Overview tab showing its details, tools and host page cards
- Sessions keep running when you switch hosts, and each host opens on the tab you left
- Host search, status dots, badges, open tab counts and a menu with edit and plugin actions on each host row
- Open pages list, Tools menu and a right side dock for plugin panels, Quick Connect and Connections
- Dashboard, Manage, Settings, admin pages, host and credential editors and command palette from Classic Layout
- Phone view with the tree first and a back button to it

## 1.0.0

### Added

- Lock, unlock and delete users through Termix actions, and see accounts with an empty password as a status tile
- See every account on a host with its groups, shell and password state
- Create users with a home folder, shell, groups, sudo and a password
- Set passwords, lock accounts and make users pick a new password
- Add and remove the SSH keys a user can log in with
- Create groups and change who is in them
- See who is logged in and recent logins
- A Users card in Host Metrics

### Changed

- Needs Termix 26.11.1 or newer

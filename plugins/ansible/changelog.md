## 1.0.0

### Added

- Edit the playbooks and other files in a project folder on a control host
- Run playbooks with check mode, diff, tags, limit and extra variables
- Use Termix hosts, folders and tags as the inventory
- Live run output, a recap per host and a run history
- Run ad-hoc modules on any hosts
- Gather facts from hosts
- Run and list playbooks through Termix actions

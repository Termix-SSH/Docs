## 1.0.0

### Added

- A terminal first layout: sessions fill the screen with one status line at the bottom
- Tiled panes like tmux or Zellij, with Ctrl+Space prefix keys to split, move, zoom, close and even them out
- Prefix keys for the palette, next and previous tab, last tab, tab numbers, rename and the status line
- Ctrl+Space works inside terminals and can be changed in Settings, Keybindings
- Command palette with hosts, open tabs, pane commands, plugin actions and settings
- Ctrl+Enter in the palette opens a host in a new pane
- Status line with numbered tabs, the focused host and the terminal's plugin buttons
- Start screen with your hosts when nothing is open
- Hosts, Quick Connect, Connections and plugin panels on the right side
- Dashboard, Manage, Settings, admin pages and the host and credential editors from Classic Layout
- Phone view with a taller status line and a back button on pages
